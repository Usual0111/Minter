BOUNTERA — ПОЛНЫЙ ПРОЕКТ

Быстрый просмотр: откройте outputs/Bountera.html двойным щелчком.
Серверный демо-режим: установите Node.js 24+, откройте папку проекта в терминале и выполните npm start. Адрес: http://127.0.0.1:4173
Для GitHub загрузите содержимое этой папки. Личные настройки .env и база прогресса .data в архив не включены.
Исходники интерфейса и изображения: assets/. Сервер: server/. Проверки: tests/.
public/ — готовая статическая версия. Пересборка: npm run build. Автономный HTML: npm run package.
Telegram SDK загружается с telegram.org для системных отступов Mini App. Игровое демо работает и без Telegram.
Реклама, пополнения и выплаты остаются демонстрационными, реальных платежей нет.
