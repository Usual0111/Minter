Для GitHub Pages замените ВСЁ содержимое публикуемой папки файлами из public этого архива (index.html и assets вместе). Не загружайте поверх только HTML из старого архива.
Исходники в корне и public содержат одинаковые актуальные ресурсы. outputs/Bountera.html — автономная версия этой же сборки.
После обновления GitHub Pages дождитесь завершения deployment, затем полностью закройте Mini App и откройте снова.
Стили и скрипты имеют версии по содержимому. Для дальнейших обновлений: npm run build, затем npm run package.
Архив не содержит личную базу данных и секреты. Игровые сохранения пользователя не сбрасываются этой визуальной правкой.
